# Prince Saini — AI Research Portfolio

A recruiter-focused personal portfolio with Apple-inspired product storytelling, minimal visual design and an interactive research-system sequence.

## Featured pinned projects

1. Dark Vessel Detection Pipeline
2. Hyperliquid Sentiment Analysis
3. OCM-3 Ocean Plastic Detection
4. Agent Pipeline

## Dark Vessel Pipeline representation

The portfolio presents the final 40-stage architecture: demo/real acquisition, VIIRS-DNB clustering, Sentinel-1 CFAR detection, AIS and thermal matching, maritime-context features, ML risk scoring, SHAP explainability, alerts, GIS outputs, dashboards, reports and system tests.

The website deliberately does not claim 96.43% accuracy. Demo-mode results are identified as synthetic and scientifically non-valid.

## Interaction and performance

- Scroll-directed cinematic sequence
- Interactive fused, detection and geospatial views
- Pointer-reactive workstation and map inspection
- Click/tap map pings and animated evidence tracks
- Cached static canvas background with lightweight dynamic drawing
- Approximately 29 FPS on standard devices and 15 FPS on constrained devices
- Off-screen animation pausing and reduced-motion support
- Responsive desktop, tablet and mobile layouts

Open `index.html` locally or deploy the folder to GitHub Pages, Netlify or Vercel.
